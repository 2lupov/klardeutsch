# Лендинг «Клар» на головній сторінці

Головна сторінка `/` стає преміальним односторінковим лендингом індивідуальних занять з німецької (A1–B2) з метою: заявка → контакт у Telegram. Увесь текст українською, mobile-first.

Авторизовані користувачі платформи не втрачають доступ: якщо є сесія, `/` показує звичний дашборд, як зараз. Лендинг бачать гості.

## Візуальний стиль

- Фон: `#10151C` (синьо-графітовий), світлі секції `#EEF2F3`, акцент аквамарин `#5FB8B0`, ціна — пісочний `#D9B87C`.
- Шрифти: Cormorant Garamond (заголовки, ціни), Manrope (текст/UI).
- Усі кольори додаються як семантичні токени лендингу в `index.css` + `tailwind.config.ts` (окремий namespace, щоб не зламати теми решти застосунку).
- Анімації: fade-up секцій зі стагером 80 мс (до 400 мс), hover-свічення аквамарином на CTA, плавна поява модалки.

## Секції

1. **Header** — логотип «Клар» (текст + мінімальна іконка), фіксований з blur-фоном, кнопка «Залишити заявку».
2. **Hero** — overline «Німецька за авторською методикою», H1 «Німецька, яка нарешті залишається в голові», підзаголовок про методику, CTA. Праворуч — SVG-банка «Wortschatz» з літерами всередині; кришка відкривається при скролі.
3. **Ціна** — стара ціна закреслена, нова крупним пісочним, підпис «за заняття · 60 хвилин · онлайн», бейдж «Перше пробне заняття — безкоштовно» з мʼякою пульсацією.
4. **Що ви отримаєте** — 3 картки SPRECHEN / WORTSCHATZ / GRAMMATIK, горизонтальний скрол зі scroll-snap.
5. **Методика** — «Не зубріння, а система»: індивідуальна програма, інтервальні повторення, матеріали після уроку.
6. **Як почати** — 3 кроки: заявка → безкоштовне пробне → індивідуальний план.
7. **Відгуки** — конфіг `TESTIMONIALS` (імʼя, текст, аватарка), scroll-snap.
8. **Фінальний CTA** — колесо фортуни на знижку з вагами шансів; після виграшу автоматично відкривається форма з підставленою знижкою.
9. **Footer** — логотип, «Клар © 2026», посилання на Політику конфіденційності.

Фонова анімація: canvas з німецькими словами/літерами (`der`, `die`, `das`, `und`, `sein`, `ä`, `ö`, `ü`, `A1`, `B1`), що повільно падають; макс 60–80 частинок (менше на мобільному), пауза коли поза екраном.

Тон: без обіцянок гарантованого результату за строк.

## Форма заявки (модалка)

- Відкривається з усіх CTA; автоматично один раз — exit-intent на десктопі або через 40 с (з хрестиком, не повторювати в цій сесії).
- Заголовок: «Залиште заявку — я звʼяжуся з вами в Telegram».
- Поля: Імʼя (обовʼязково), Телефон з маскою +380 (обовʼязково), Telegram @нік (опційно, латиниця/цифри/_), Пошта (опційно, email), Рівень (з нуля / A1–A2 / B1–B2 / не знаю).
- Обовʼязковий чекбокс згоди з посиланням на Політику; сабміт неактивний без нього.
- Success: «Дякуємо! Я звʼяжуся з вами в Telegram найближчим часом.»

## Бекенд

- Нова таблиця `leads`: name, phone, telegram, email, level, consent, consent_at, discount, utm_source, utm_medium, utm_campaign, status default `'new'`, created_at.
- RLS: анонімам лише INSERT з CHECK-обмеженнями довжини полів і `consent = true`; читання — лише адміну. GRANT INSERT для `anon`/`authenticated`, повний доступ `service_role`.
- UTM зчитуються з URL і зберігаються із заявкою.
- Серверна функція `notify-lead` надсилає сповіщення в Telegram (імʼя, телефон, Telegram, пошта, рівень, знижка, UTM) через уже налаштований бот проєкту.
- Meta Pixel: ID з `VITE_META_PIXEL_ID`, `fbq('track','Lead')` після успішного запису.

## SEO

Оновлення title/description/og під лендинг, JSON-LD `Course`, canonical, `robots.txt` (закрити `/api/`), sitemap.xml, фавікон із логотипу. Окрема сторінка Політики конфіденційності для лендингу.

## Технічні деталі

- Нові файли: `src/pages/KlarLanding.tsx` + компоненти в `src/components/klar/` (Header, Hero, WortschatzJar, PriceBlock, Benefits, Method, Steps, Testimonials, FortuneWheel, LeadModal, WordRain, Footer).
- `src/pages/Index.tsx`: гість → `KlarLanding`, авторизований → поточний дашборд (наявна логіка зберігається).
- Валідація форми — zod + client-side; сервер додатково обмежує довжини через CHECK.
- Fade-up через IntersectionObserver, canvas-анімація на `requestAnimationFrame` з паузою по видимості та `prefers-reduced-motion`.
