# Покращення дизайну сторінок учня

## Мета
Освіжити обидві студентські сторінки — головну «Моє навчання» (`/academy` для учня) і «Мої завдання» (`/assignments`) — у мінімалістичному стилі, додати компактну смужку статистики та картку «Далі», не перевантажуючи сторінку.

## Що робимо

### 1. Головна «Моє навчання» (`src/pages/StudentAcademy.tsx`)

- **Смужка статистики** під заголовком — 3 компактні показники (маленькі цифри, маленькі підписи, без важких карток):
  - Активні — невиконані тести + домашні завдання
  - Оцінені — роботи з оцінкою
  - Середній бал — середнє з `student_submissions` (`grade ?? auto_score`) та `tutoring_homework.grade`, шкала 0–100
  - Смужка ховається, якщо даних немає зовсім
- **Картка «Далі»** — найтерміновіше завдання:
  - обирається з невиконаних тестів/домашки з найближчим `due_at`; якщо дедлайнів немає — найновіше призначене
  - показує назву, чип типу, дедлайн (відносний формат «до 12 вер.», або «термін минув»), кнопку «Виконати»
  - ховається, коли все виконано
- **Охайніший список**: вирівняні відступи, єдина типографіка, легкий hover (рамка + мікро-зсув), уніфіковані статус-бейджі, іконки в стриманих кружках
- **Порожній стан**: маленька панда (`panda-sleeping` / `panda-celebrating`) замість сірої іконки
- Вкладки (Тести / Домашка / Читання / Курси) і вся логіка завантаження не змінюються

### 2. «Мої завдання» (`src/pages/StudentAssignments.tsx`)

- Прибрати яскраві градієнтні шапки карток → мінімалістичні картки: світла поверхня, кольорова іконка + чип типу, статус-бейдж
- Ті самі відступи, фільтри-чипи та hover, що й на головній — єдиний стиль обох сторінок
- Порожній стан з пандою
- Фільтри (Активні / Виконані / Усі), статуси, оцінки — без змін логіки

## Дані
Нові таблиці не потрібні, усе вже в БД:
- `student_assignments` (`status`, `due_at`, `type`) — активні/оцінені, картка «Далі»
- `student_submissions` (`grade`, `auto_score`) — середній бал
- `tutoring_homework` (`grade`) — середній бал (додатково)

## Технічні деталі
- Файли: `src/pages/StudentAcademy.tsx`, `src/pages/StudentAssignments.tsx`
- У `StudentAcademy` додається один запит до `student_submissions` за `user.id` (оцінені + середній бал); домашні оцінки вже частково підтягуються
- Стилі — лише дизайн-токени (`bg-card`, `border-border`, `text-muted-foreground`, `primary`), заголовки Space Grotesk, легкі framer-motion появи (stagger)
- Українська мова інтерфейсу зберігається; механізм `t()` на `/assignments` не чіпаємо
- Без змін у БД, edge functions та RLS

## Перевірка
- Build без помилок
- Візуальна перевірка через прев’ю: якщо є доступ до студентського акаунту (nickname-логін) — огляд головної учня; інакше перевірка коду + рендер порожніх станів
- Переконатися, що смужка статистики та картка «Далі» коректно реагують на порожні дані і ховаються
