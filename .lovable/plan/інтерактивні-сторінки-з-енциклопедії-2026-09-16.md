# Інтерактивні сторінки з енциклопедії

Замість фото сторінки учень отримує живу сторінку: анімована схема (планети рухаються по орбітах), клікабельні підписи, таблиці, лексика і мінітест. Текст — тільки німецькою.

## Як це працює для вас

1. В адмінці, у розділі підручників/книг, вибираєте сторінку (фото) і тиснете «Зробити інтерактивну сторінку».
2. AI читає фото і збирає сторінку з готових блоків. Ви бачите одразу попередній перегляд.
3. Кожен блок можна відредагувати вручну: змінити заголовок, текст, підписи, швидкість анімації, порядок блоків, видалити зайве.
4. Зберігаєте — сторінка стає доступною учню, і її ж можна показати на живому уроці синхронно з учнем.

## Набір анімованих блоків

- **Орбіти** — центральне тіло + об'єкти, що обертаються по еліпсах з різною швидкістю; клік по об'єкту відкриває його опис.
- **Схема з підписами (hotspots)** — оригінальне фото або окреме зображення з пронумерованими точками; клік показує підпис.
- **Шкала / масштаб** — горизонтальна вісь з мітками (напр. відстані до планет), з плавним появленням.
- **Картки-факти** — сітка карток, що перевертаються, з ключовими даними.
- **Таблиця** — дані зі сторінки, з підсвіткою рядка при наведенні.
- **Лексика** — слова з артиклями, озвучка через наш голосовий сервіс, кнопка «до мого словника».
- **Текстовий блок** — заголовок + абзаци німецькою, з акцентами на термінах.
- **Мінітест** — 3–6 питань з варіантами, миттєва перевірка.

Анімації — плавні, у стилі сайту (темний фон, жовтий акцент), із повагою до «зменшити анімацію» в системних налаштуваннях.

## Де це видно

- **Учень:** окрема сторінка інтерактивного уроку зі списком блоків, прогресом і результатом мінітесту.
- **Живий урок:** кнопка «Показати інтерактивну сторінку» — учню відкривається та сама сторінка, синхронно з вами (як зараз працює показ сторінки підручника).

## Технічна частина

- Нова таблиця `interactive_pages`: `id`, `book_id`, `page_id` (nullable), `title`, `level`, `scene` (jsonb — масив блоків), `status` (draft/published), `owner_id`, timestamps. RLS: вчитель/адмін — повний доступ до своїх, учні — SELECT для published. GRANT для `authenticated` та `service_role`.
- Edge function `generate-interactive-page`: JWT + перевірка ролі `admin`/`teacher` (як у `parse-book-page`), завантажує скан із бакета `book-pages`, шле його в Lovable AI Gateway (`/v1/chat/completions`, `google/gemini-3.7-flash`, `image_url` + `response_format: json_object`), повертає валідовану JSON-сцену з блоками вище. Без штучних таймаутів; обробка 402/429/5xx за контрактом шлюзу.
- Схема сцени описується в `src/lib/interactivePages.ts` (типи блоків + санітизація), щоб редактор і рендер користувались одним джерелом.
- Рендер: `src/components/interactive/InteractiveScene.tsx` + компоненти на блок (`OrbitBlock`, `HotspotBlock`, `ScaleBlock`, `FactCardsBlock`, `TableBlock`, `VocabBlock`, `TextBlock`, `QuizBlock`), анімації через framer-motion (орбіти — CSS/rAF, без важких залежностей).
- Адмінка: новий екран `src/pages/admin-v2/pages/InteractivePagesPage.tsx` (генерація, список, редактор блоків, попередній перегляд, публікація), точка входу з `BooksPage.tsx`.
- Учень: маршрут `/interactive/:id` (`src/pages/InteractivePage.tsx`), доступний для керованих учнів.
- Живий урок: у `LiveClassPage.tsx` кнопка показу — бродкаст `interactive_page` через існуючий realtime-канал; `LiveClass.tsx` рендерить `InteractiveScene` під дошкою.
- Зображення для hotspot-блоків беруться зі вже завантаженого скану (signed URL з `book-pages`), нові картинки не генеруються.

## Обсяг першої ітерації

Генерація + редактор + перегляд учнем + показ на живому уроці, з усіма 8 блоками. Складніші сцени (3D, вільна AI-анімація) — не входять.
