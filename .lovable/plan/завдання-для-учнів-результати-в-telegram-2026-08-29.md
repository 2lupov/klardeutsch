# Завдання для учнів + результати в Telegram

Нова секція «Завдання» в адмінці: створюєте тест, домашку, письмо або аудіо-завдання конкретному учню (або групі учнів). Учень бачить це у своєму кабінеті, виконує — і результат одразу прилітає вам у Telegram.

## Що зʼявиться

### 1. Адмінка → «Завдання» (нова вкладка, українською)
- Список усіх виданих завдань: учень, тип, статус (видано / здано / перевірено), оцінка, дата.
- Кнопка «Нове завдання»: обираєте учня (або кілька), тип, дедлайн, опис.
- Чотири типи:
  - **Тест** — конструктор питань (питання, 2-4 варіанти, правильна відповідь, пояснення). Плюс кнопка «Згенерувати AI»: вказуєте тему, рівень (A1–C1), кількість питань — AI створює тест, ви редагуєте перед видачею.
  - **Домашка** — текстовий опис + учень відповідає текстом та/або прикріплює фото/файли.
  - **Письмо (AI-перевірка)** — тема й вимоги; AI дає оцінку та фідбек, ви можете переписати оцінку вручну.
  - **Аудіо / вимова** — учень записує голос, запис зберігається; ви слухаєте і ставите оцінку.
- Екран перевірки: відповіді учня, файли/аудіо, авто-бал тесту, поле фідбеку та фінальної оцінки.

### 2. Кабінет учня
Завдання додаються в наявний список «Мої завдання» (`/assignments`) поруч із домашкою та уроками. Окремі екрани виконання:
- тест — питання по одному, прогрес, результат у кінці;
- домашка — текст + завантаження файлів (як зараз);
- письмо — редактор із підрахунком слів, після відправки видно AI-фідбек;
- аудіо — запис голосу з браузера, прослухати/перезаписати, потім відправити.

### 3. Telegram-повідомлення вам
Коли учень здає завдання, у ваш адмін-чат приходить:
- імʼя учня, тип і назва завдання;
- для тесту — бал (напр. 8/10, 80%) і список помилок;
- для письма — AI-оцінка й короткий фідбек;
- для домашки/аудіо — що прикріплено + посилання на перевірку в адмінці.
Додатково: щоденне зведення (скільки завдань здано, хто прострочив) — за бажанням увімкнути пізніше.

## Технічна частина

**База даних (одна міграція)**
- `student_assignments` — teacher_id, student_id, type (`test | homework | writing | audio`), title, instructions, payload jsonb (питання тесту / вимоги), level, due_at, status, created_at/updated_at.
- `student_submissions` — assignment_id, student_id, answers jsonb, text, files jsonb, audio_path, auto_score, ai_feedback, grade, teacher_feedback, status (`submitted | graded`), submitted_at, graded_at.
- GRANT для `authenticated` + `service_role`; RLS: учень бачить і здає лише своє, вчитель/адмін — своїх учнів (перевірка через `created_by_teacher_id` у `profiles`, `tutoring_relationships` та `has_role(...,'admin')`).
- Тригери `update_updated_at_column`.

**Storage**
- Новий приватний бакет `student-submissions` (файли домашки + аудіо), політики: учень пише у свою теку, вчитель/адмін читає.

**Edge Functions**
- `generate-student-test` — Lovable AI (`google/gemini-3.7-flash`), структурований JSON із питаннями; помилки шлюзу (402/429) показуються в UI.
- `grade-student-writing` — AI-перевірка письма (оцінка + фідбек), використовує підхід наявної `check-writing`.
- `submit-student-assignment` — валідація (Zod), авто-підрахунок тесту на сервері (правильні відповіді ніколи не йдуть у клієнт), запис у `student_submissions`, потім Telegram-повідомлення через `TELEGRAM_BOT_TOKEN` в адмін-чат (той самий ADMIN_CHAT_ID, що в `notify-lead`).
- Для тесту клієнт отримує питання без `correct_index`.

**Фронтенд**
- `src/pages/admin-v2/pages/AssignmentsPage.tsx` + пункт меню в `AdminV2.tsx` (з підтримкою темного режиму адмінки).
- `src/pages/student/AssignmentRunner.tsx` (тест / письмо / аудіо) + маршрут; інтеграція у `StudentAssignments.tsx`.
- Аудіо через MediaRecorder з очищенням `URL.revokeObjectURL`.

## Порядок робіт
1. Міграція БД + бакет.
2. Edge Functions (генерація тесту, перевірка письма, здача завдання + Telegram).
3. Адмінка: список, конструктор, AI-генерація, екран перевірки.
4. Кабінет учня: 4 екрани виконання.
5. Перевірка: створити тестове завдання, здати від імені учня, підтвердити повідомлення в Telegram.
